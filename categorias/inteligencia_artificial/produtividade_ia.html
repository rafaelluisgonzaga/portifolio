Sobre o Projeto

🎧 Este projeto é a Landing Page do conceito PeaceFm, criada durante a Imersão IA (Alura & Google). O objetivo foi demonstrar o poder da Engenharia de Prompts para transformar um simples rascunho em uma página web moderna em poucos minutos, elevando a produtividade no design e desenvolvimento.

💡 O Desafio e o Estudo de Caso

O projeto começou com um esboço simples e a referência visual do site K-LOVE. A evolução ocorreu ao refinar cuidadosamente o prompt, levando a uma entrega de código final muito superior — moderno, responsivo e com foco total no CTA.

❌ 1. Prompt Inicial (Vago)

  • Gerava um site completo em vez de uma landing page
  • Faltava especificação de tecnologias (Tailwind CSS)
  • CTA pouco otimizado (“OUÇA AGORA” sem destaque)

✔️ 2. Prompt Otimizado (Final)

  • Define landing page moderna
  • Usa Tailwind CSS
  • Dá foco ao CTA "OUÇA AGORA"
  • Simula player com JavaScript

🛠️ Resultado e Tecnologias

  • HTML5: Código limpo e semântico
  • Tailwind CSS: Layout totalmente responsivo
  • JavaScript puro: Player simulado (Ouvir/Parar)

✨ Funcionalidades da UI

  • CTA "OUÇA AO VIVO AGORA" com alto destaque
  • Seção de benefícios (3 blocos explicativos)
  • Seção mobile para download do app

📚 Contexto da Imersão

Este projeto demonstra a aplicação prática da aula sobre produtividade com IA no Google Workspace. A capacidade de gerar interfaces completas via prompt detalhado mostra como a IA acelera o desenvolvimento, permitindo foco em design e estratégia.
