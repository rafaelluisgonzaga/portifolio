ML End-to-End em Produção

Pipeline completo de Machine Learning com deploy via API

Ver no GitHub

Sobre o Projeto

📊 Este projeto apresenta uma solução completa de Machine Learning end-to-end, cobrindo todas as etapas do ciclo de vida do modelo: análise exploratória de dados, pré-processamento, treinamento, avaliação, persistência do modelo e exposição via API REST para inferência em produção.

🔨 O que o Projeto Faz

  • 📈 Realiza EDA e tratamento de dados reais
  • 🧩 Aplica pipeline de pré-processamento com scikit-learn
  • 🤖 Treina modelo de classificação para previsão de churn
  • 💾 Persiste o modelo treinado em disco
  • 🌐 Disponibiliza inferência via API FastAPI

💻 Tecnologias Utilizadas

  • 🐍 Python
  • 📊 pandas & NumPy
  • 🤖 scikit-learn
  • ⚡ FastAPI & Uvicorn
  • 💾 joblib

🧠 Arquitetura da Solução

  • Pipeline: ColumnTransformer + Pipeline
  • Pré-processamento: Numéricos e categóricos
  • Modelo: Regressão Logística
  • Persistência: Artefato salvo com joblib
  • Serviço: API REST com FastAPI

🚨 Caso Real de Produção

Durante o deploy da API, foi identificado e resolvido um problema clássico de training–serving skew, causado por desalinhamento de schema e tipos entre o treino e a inferência. A solução envolveu correção do target, limpeza de dados e re-treinamento do modelo.

Como executar: Crie um ambiente virtual Python, instale as dependências, execute a API com Uvicorn e realize chamadas de inferência via Swagger UI.
